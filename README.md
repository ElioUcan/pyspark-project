## ✨ Features
- Process NYC yellow taxi trip records stored in Parquet format with PySpark
- Containerized PySpark environment via Docker Compose — no local Spark installation required
- Batch data transformations on large-scale trip datasets (January 2023)

## 🎯 Uses
Data engineering learning project exploring distributed data processing with PySpark on real-world NYC TLC taxi data. Demonstrates how to run Spark jobs in a containerized environment without manual cluster setup.
